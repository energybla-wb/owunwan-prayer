이용 방법

기도제목을 나눠보세요

1
링크 접속
공유받은 링크를 클릭하여 접속합니다.
owunwan-project.vercel.app
🙏
오운완
함께 기도해요
2
로그인
이름과 비밀번호(숫자 4자리)를 입력합니다. 처음 오시는 분은 원하는 이름과 비밀번호를 설정하면 자동으로 계정이 생성됩니다.
이름
비밀번호 (숫자 4자리)
로그인
💡 비밀번호를 잊지 마세요! 다음에 같은 이름+비밀번호로 로그인해야 기도제목을 수정할 수 있습니다.
3
기도작성 페이지로 이동
로그인하면 대시보드가 보입니다. "기도작성 페이지로 이동" 버튼을 눌러주세요.
4
주차 선택
상단의 주차 탭에서 기도제목을 작성할 주를 선택합니다. 현재 주차와 지난 주차가 활성화되어 있습니다.
1주 2주 3주 4주 5주
5
기도제목 작성
기도제목을 입력하고, 공개 또는 비공개를 선택한 뒤 등록 버튼을 누릅니다.
🌐 공개 — 모든 사람이 볼 수 있습니다
🔒 비공개 — 관리자만 볼 수 있습니다
6
댓글로 서로 격려하기
다른 사람의 기도제목에 댓글을 달아 서로 격려해주세요. 본인이 작성한 댓글은 수정·삭제할 수 있습니다.
홈 화면 설치

앱처럼 바로 접속하기

홈 화면에 추가하면 매번 링크를 찾지 않아도 앱 아이콘을 눌러 바로 접속할 수 있습니다.

1
Safari로 접속
반드시 Safari 브라우저로 접속해야 합니다. 카카오톡 내장 브라우저에서는 설치가 안 됩니다.
💡 카카오톡에서 링크를 받았다면, 오른쪽 하단 "Safari로 열기" 또는 "..." 버튼을 눌러 Safari에서 열어주세요.
2
공유 버튼 누르기
Safari 화면 하단 가운데에 있는 공유 버튼(네모에서 화살표가 올라가는 아이콘)을 누릅니다.
⬆️
Safari 하단 중앙의 이 아이콘
3
"홈 화면에 추가" 선택
공유 메뉴에서 아래로 스크롤하면 "홈 화면에 추가" 항목이 있습니다.
메시지
메일
➕ 홈 화면에 추가
즐겨찾기에 추가
4
"추가" 버튼 누르기
오른쪽 상단의 "추가"를 누르면 완료! 홈 화면에 기도손 아이콘이 나타납니다.
🙏
오운완
홈 화면에서 바로 접속!
1
Chrome으로 접속
Chrome 브라우저로 접속해야 합니다. 삼성 인터넷이나 카카오톡 내장 브라우저에서는 설치가 안 될 수 있습니다.
💡 카카오톡에서 링크를 받았다면, 오른쪽 하단 "..." → "다른 브라우저로 열기"를 눌러 Chrome에서 열어주세요.
2
메뉴 열기
Chrome 화면 오른쪽 상단에 있는 점 세 개(⋮) 버튼을 누릅니다.
owunwan-project.vercel.app
⋮
← 이 버튼을 누르세요
3
"홈 화면에 추가" 또는 "앱 설치" 선택
메뉴에서 "홈 화면에 추가" 또는 "앱 설치"를 선택합니다. (Chrome 버전에 따라 문구가 다를 수 있어요)
새 탭
북마크
📲 홈 화면에 추가
설정
4
"추가" 누르면 완료!
확인 팝업에서 "추가"를 누르면 홈 화면에 아이콘이 생깁니다.
🙏
